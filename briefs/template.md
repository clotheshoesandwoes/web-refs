# Brief template

Fill this in before asking a chat to build a page. A brief with empty lines gets filled in with defaults (Inter, gray, cards, fade-ups).

```
Subject:     who it's for, with real details (address, menu, quotes, photos, the owner's own words)
The idea:    one object, ritual or medium from the subject, in one sentence
Reference:   one site from web-refs/sites + the exact thing to take from it
Type:        two named faces (from Fonts In Use or a foundry), what each is for
Motion:      one moment, what triggers it, why the subject would do that. Everything else is still
Done:        phone + desktop screenshot, judged by eye
```

Rules:

- The chat states the idea back in one sentence before writing any code.
- The banned list in `~/.claude/CLAUDE.md` ("No AI UI slop") applies.

## Worked example (Izakaya Sakura, v3, passed review)

```
Subject:     Izakaya Sakura, 3904 Convoy St, San Diego. Real menu, real prices, real Yelp/Tripadvisor quotes
The idea:    a printed izakaya menu; you enter through a noren curtain, and orders are counted in 正 tally strokes
Reference:   printed Japanese menus: dot leaders, ruled heads, a red hanko stamp
Type:        Shippori Mincho (heads, quotes), Zen Kaku Gothic New (body, prices)
Motion:      the curtain parts once on entry; tally strokes draw when you mark a dish. Nothing else moves
Done:        phone + desktop screenshot
```
